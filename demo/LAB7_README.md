Лабораторна робота 7

Перероблено на Maven multi-module проєкт. Кореневий pom.xml має packaging pom і містить три модулі.

repair-orders-service працює на порту 8081. У нього перенесено основну частину початкового проєкту: ремонтні замовлення, базу даних H2, Liquibase, Spring Security, Quartz, AOP, веб-сторінки та REST API.

repair-estimates-service працює на порту 8083. Це окремий REST-сервіс для розрахунку вартості ремонту. Він приймає опис проблеми та повертає вартість деталей, роботи і загальну суму.

customer-alerts-service працює на порту 8084. Це окремий REST-сервіс для створення сповіщення клієнту.

Кожен модуль має власний pom.xml, головний клас Spring Boot, application.yml і Dockerfile. Модулі не залежать один від одного через Maven. Спільна тестова залежність spring-boot-starter-test визначена в кореневому pom.xml.

Порт 8082 залишено для Keycloak, тому конфігурацію redirect URI змінено на порт 8081 для сервісу замовлень.

Усі тести завершилися без помилок.
